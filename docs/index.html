A signal for every
observable state.

Blinkdock reflects Claude Code's latest hook event. When events stop arriving, it reports uncertainty.

Listening
Ready for a prompt.
Working
A prompt or tool is active.
Waiting for you
Your input is needed.
Done

Background work
Background tasks were reported.
Error
A stop or API failure was reported.
Status unknown
No recent event to rely on.
Offline
No session is currently tracked.

Manual interruptions and some background events may not emit a matching hook. Read the behavior and limits.

Manual and project-only installation
PowerShell 
git clone https://github.com/benmaster82/Blinkdock.git
cd Blinkdock
python -m pip install -r requirements.txt
python setup.py

Setup installs global Claude Code hooks, enables launch at Windows sign-in, and starts the widget. Existing Claude settings are preserved and backed up.

Prefer a ZIP download?

Extract the ZIP, open PowerShell in that folder, and run python -m pip install -r requirements.txt. Then double-click Install.cmd.

A few good
questions.

More detail in the documentation.

Can I approve a request from the widget?

Approvals and replies happen in the Claude Code terminal. Blinkdock shows when you're needed and can bring a launcher-linked session's terminal forward.

Does it need an API key or another account?

Blinkdock uses local hook events from your existing Claude Code installation. It doesn't need its own API key or account, and it doesn't send your session status to a server.

Does it run Git while Claude is working?

The hooks write small local records. Git status runs asynchronously only when you open the file panel, roughly every two seconds. Hook execution still has some overhead; Blinkdock does not claim zero performance impact.

Can I use it on macOS, Linux, or with other agents?

The supported setup is local Claude Code CLI sessions on Windows. Terminal focus, autostart, and notification sounds are Windows-specific. Other coding agents and Claude's web or desktop app are not currently supported.

How do I remove it?

Run Uninstall.cmd or python setup.py uninstall. This removes Blinkdock's global hooks and autostart entry and stops the widget. Hooks installed for individual projects need to be removed separately. Local preferences are kept.
